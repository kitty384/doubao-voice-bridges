# Doubao Voice Bridges

两个配合豆包语音输入法使用的 macOS 菜单栏工具：用耳机线控发送 Fn / Globe 点按，以及通过网易 UU 远程把本地转写的文字粘贴到远端 Mac。

| 工具 | 当前版本 | 作用 |
| --- | --- | --- |
| [豆包耳机语音桥接](apps/headset-bridge/) | 1.1 | 把特定 3.5 mm 耳机线控中间键转换为约 60 毫秒的 Fn 脉冲 |
| [UU 远控听写 Fn](apps/uu-voice-bridge/) | 2.5.0 | 在本地发送框接收豆包转写，经 UU 文字剪贴板同步后向原远端窗口发送粘贴指令 |

两个工具均可单独使用，也可配合使用。桥接程序不录音、不提供语音识别服务、不自行联网；录音和转写由豆包完成，远程连接和剪贴板同步由 UU 完成。

## UU 远程 Mac → Mac 的操作

先确认豆包在普通本地输入框内可以用 Fn 听写，并确认从本地复制一段文字后，能在远端 Mac 手动粘贴。

1. 在 UU 连接窗口中点击远端需要输入文字的位置。
2. 从「远控听写 Fn」菜单启用听写，**轻按一次 Fn，打开本地发送框**。
3. 在发送框内，按照豆包自身的 Fn 模式开始和结束听写；框内 Fn 交给豆包处理。
4. 确认文字出现，可继续编辑，然后**按 Return 发送**。Esc 取消；输入法仍有候选或标记文本时，按键先交给输入法处理。

发送框由本工具创建，并非 UU 自带的剪贴板面板。第一次 Fn 只负责开框，不同时开始录音；后续 Fn 也不代替 Return 发送。这里保留 2.5.0 的操作流程，未包含单击切换录音的实验版本。

实体键盘另保留长按 Fn、松开后尝试自动提交的路径。它依赖豆包接受合成 Fn 及系统监听顺序，不能保证适用于所有环境。建议先用上述分步操作验证完整链路。

配合耳机桥接时，UU 前台的第一次线控点击提供同一个开框入口。发送框内后续点击能否启停豆包，取决于豆包的 Fn 模式及其是否接受合成事件。耳机程序发出的是短 Fn 脉冲，不输出 Home 或 Control，也不把按住线控的时长转换成 Fn 长按。

## 构建和安装

在 macOS 上安装 Xcode Command Line Tools。构建两个工具需要 macOS 13 或更新版本，以及支持 Swift 5.9 或更新版本的工具链；耳机子项目本身的最低目标系统为 macOS 12。无第三方包依赖。

在仓库根目录执行：

```sh
bash scripts/test.sh
bash scripts/build.sh
```

生成的应用分别位于：

- `apps/headset-bridge/dist/DoubaoHeadsetBridge.app`
- `apps/uu-voice-bridge/dist/远控听写 Fn.app`

两个应用均包含 Apple Silicon 和 Intel 架构。构建脚本只生成产物，不安装或启动菜单栏应用。先退出旧版，再把所需应用放到固定位置，例如「应用程序」，只启动这一份。

应用使用 ad-hoc 临时签名，没有 Apple 开发者身份签名或公证。可自行构建；对可信构建，按 macOS 提供的「隐私与安全性 → 仍要打开」流程处理，无需关闭系统安全机制。

UU 工具需要「辅助功能」和「输入监控」，每次启动默认暂停，授权后需手动启用。耳机工具需要辅助功能来发送按键；独占打开匹配的线控接口还可能需要输入监控，以实际接管结果为准。豆包另行获得麦克风权限。详见 [隐私与权限](docs/privacy-and-permissions.md)。

## 支持和验证范围

- 目标链路为本地 Mac → UU → 远端 Mac，要求 UU 文字剪贴板同步可用；不宣称 Windows 远端兼容。
- 耳机工具只匹配 `Product=Headset`、`Transport=Audio`、消费者用法页 `12`、主用法 `1` 的接口，不覆盖所有 3.5 mm、USB 或蓝牙耳机。
- Fn 监听采用实际 Fn / Globe 修饰键事件，键码为 `63`。安全输入、快捷键冲突、事件监听顺序和软件版本差异均可能影响触发；合成 Fn 不等同于硬件按键。
- 发送会覆盖并保留系统剪贴板。程序只确认本机粘贴指令已发出，不能确认远端实际收到文字。发送期间保持 UU 目标窗口有效，避免切换焦点或改写剪贴板。

根测试脚本运行纯逻辑测试；macOS CI 运行相同测试及双架构构建。额外的 AppKit、事件构造和隔离剪贴板自检需有图形桌面的系统会话，均不能替代真实耳机、豆包录音和双机验收。

测试范围和手工检查清单见 [耳机验证说明](apps/headset-bridge/docs/validation.md) 与 [UU 验证说明](apps/uu-voice-bridge/docs/validation.md)。遇到授权无效、没有文字或无法远端粘贴时，按 [排错说明](docs/troubleshooting.md) 逐步定位。
