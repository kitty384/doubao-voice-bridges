## 手工验收

1. 退出其他同名应用。确认本地豆包在普通输入框里通过原生 Fn 可以录音、结束并落下文字。
2. 单独检查 UU 的本地复制 → 远端粘贴，确认文字同步开启且可用。
3. 启动本工具，确认辅助功能与输入监控实际生效，然后手动启用监听。
4. UU 前台点击远端空白文本框，短按 Fn 应打开本地发送框。框内再使用豆包 Fn，确认有转写文字，Return 发送，远端应出现本轮文字。
5. 测试 Esc 取消、中文候选确认、Fn 组合键、切换出 UU 后 Fn 原有行为，以及暂停后不再开框。
6. 长按录音路径单独验收：持续录音、松开、转写稳定、远端结果均须确认。若失败，使用双步骤流程并记录系统、豆包、UU 版本。
7. 最后才接入耳机桥接，分别确认第一次线控开框、框内启停豆包、实际转写及 Return 发送。不要仅凭录音动画或开框判断成功。

报告问题前检查日志与诊断输出中的设备名、前台应用和本机状态，勿公开真实转写或剪贴板内容。
